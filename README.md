Income Expense Calculator

About Project

I created this project to track income and expenses easily.
User can add income and expense details and see total balance.

Features

* Add income and expense
* Edit existing data
* Delete entries with confirmation
* Filter data (All / Income / Expense)
* Show total income, total expense, and balance
* Reset input fields
* Data is saved using localStorage
* Responsive design (works in mobile and desktop)

Technologies Used

* HTML
* Tailwind CSS
* JavaScript

 How to Run

1. Download the project file
2. Save it as **index.html**
3. Open in any browser

 How it Works

* User enters description and amount
* Select income or expense
* Click Add button
* Data will show in list
* User can edit or delete anytime
* Data will not be lost after refresh

Conclusion

This project helped me understand CRUD operations, localStorage, and basic UI design using Tailwind CSS.
